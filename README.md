# The Corner Café — Your Turn

Welcome! This is a real café website with a few pieces left unfinished on purpose.
The Navbar and Footer are already built — use them as your reference for how
HTML and CSS work together. Your job is to finish the **Hero**, **About**, and
**Menu** sections.

## How to work on this

1. Open this folder in VS Code.
2. Open `index.html` in your browser (right-click → "Open with Live Server", or
   just double-click the file) so you can see your changes as you make them.
3. Look for comments that start with `YOUR TURN` in both `index.html` and
   `styles.css` — each one tells you exactly what to add.
4. Save the file and refresh your browser after every change.

## What you'll practice

| Concept | Where |
|---|---|
| Headings & paragraphs | Hero and About sections |
| Images & alt text | Hero image |
| Lists | Menu section |
| Links styled as buttons | Hero button |
| Color, font, background, border | `.hero`, `#about`, `#menu`, `.btn` rules |
| Spacing & alignment | Padding and margin on the same rules |
| Hover states | `.btn:hover` |

## Tip

If you get stuck, look at how `.navbar` or `#contact` is styled in
`styles.css` — the same properties you need are already used there, just
with different values.
